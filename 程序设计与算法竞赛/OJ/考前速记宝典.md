## 分组详解

### 🥇 第一组：排序 + 贪心（送分）

#### 1. 校赛排名
```cpp
bool cmp(Node a, Node b) {
    if (a.ac != b.ac)  return a.ac > b.ac;      // 题数降序
    if (a.time != b.time) return a.time < b.time; // 罚时升序
    return a.idx < b.idx;                         // 输入顺序升序
}
sort(v.begin(), v.end(), cmp);
```
> **考点**：cmp 写法；存原始下标 idx

#### 2. 有序数组元素安插
```cpp
auto it = lower_bound(seq.begin(), seq.end(), num);
seq.insert(it, num);
// 中位数
if (n % 2 == 1)  return nums[n/2];
else             return (nums[n/2-1] + nums[n/2]) / 2.0;
```
> **考点**：`lower_bound`（第一个 ≥ num 的位置）；`insert` 用法

#### 3. 勇者斗恶龙
```cpp
sort(dragons, dragons+n);
sort(knights, knights+m);
int i=0, j=0, cost=0;
while (i < n && j < m) {
    if (dragons[i] <= knights[j]) { cost += knights[j]; i++; j++; }
    else j++;
}
if (i == n) cout << cost; else cout << "Loowater is doomed!";
```
> **考点**：双排序+双指针贪心，一个骑士砍一个头

### ♻️ 第二组：递归 + 分治 + 数论

#### 4. 归并排序（填空）
```cpp
void merge_sort(int *A, int x, int y, int *T) {
    if (y - x > 1) {        // ← 填空：区间长度>1才分
        int m = x + (y-x)/2;
        merge_sort(A, x, m, T);
        merge_sort(A, m, y, T);
        int p = x, q = m, i = x;
        while (p < m || q < y) {
            if (q >= y || (p < m && A[p] <= A[q]))
                T[i++] = A[p++];
            else T[i++] = A[q++];
        }
        for (i = x; i < y; i++) A[i] = T[i];
    }
}
```
> **填空**：`if (y - x > 1)` —— 区间长度 > 1 才分

#### 5. 最大子数组和（填空）
```cpp
int maxSubArraySum(arr, low, high) {
    if (low == high) return arr[low];
    int mid = (low + high) / 2;                  // ← 填空
    int leftMax  = maxSubArraySum(arr, low, mid);
    int rightMax = maxSubArraySum(arr, mid+1, high);
    int crossMax = maxCrossingSum(arr, low, mid, high);
    return max({leftMax, rightMax, crossMax});
}
```
> **填空**：`int mid = (low + high) / 2;`
> 
> **跨中点** = 从中点向左最大 + 从中点向右最大

#### 6. 龙龙
```cpp
for (long long i = 1; i <= n;) {
    long long v = n / i;
    long long next = n / v + 1;
    res += v * (next - i);
    i = next;
}
```
> **考点**：`n/i` 只有 O(√n) 种取值；`next = n/(n/i) + 1`

### 👮 第三组：士兵四件套（区分是关键！）

四道题**规则一样**（反复删奇数位或偶数位直到≤3人），但 **问法不同**：

| 题名 | 问什么 | Base Case | 公式 |
|------|--------|-----------|------|
| **不被选中巡逻最小编号** | 第一个安全的编号 | ≤2安全，=3必死 | `safe(t,b)` 递归判断单个位置 |
| **不巡逻的士兵** | 安全位置总数 | `<3` 返回 `i`，`=3` 返回 `0` | `f(i)=f(i/2)+f((i+1)/2)` |
| **判断士兵是否巡逻** | 给定位置 Y/N | `<3` 返回 `0`，`=3` 返回 `1` | 步长定位 `(f-a)%(2*step)==0` |
| **巡逻的士兵** | 方案数 | `<3` 返回 `0`，`=3` 返回 `1` | `f(i)=f(i/2)+f((i+1)/2)` |

#### 7. 不被选中巡逻的士兵最小编号
```cpp
bool safe(int t, int b) {
    if (t <= 2) return 1;
    if (t == 3) return 0;
    bool SO = (b % 2 == 1) ? 1 : safe(t/2, b/2);
    bool SE = (b % 2 == 0) ? 1 : safe((t+1)/2, (b+1)/2);
    return SO && SE;
}
// main: from i=1 to t, 第一个 safe(t,i)==true 的就是答案
```

#### 8. 不巡逻的士兵
```cpp
ll f(int i) {
    if (i < 3) return i;         // i 个士兵全部安全
    if (i == 3) return 0;        // 3人全去巡逻
    if (fa.count(i)) return fa[i];
    return fa[i] = f(i/2) + f((i+1)/2);
}
```

#### 9. 判断士兵是否巡逻
```cpp
int judge(int n, int a, int step, int f) {
    if (n < 3) return 0;
    if (n == 3) return 1;
    if ((f - a) % (2 * step) == 0)          // 在奇数位组
        return judge((n+1)/2, a, step*2, f);
    else                                    // 在偶数位组
        return judge(n/2, a+step, step*2, f);
}
```

#### 10. 巡逻的士兵
```cpp
ll f(int i) {
    if (i < 3) return 0;
    if (i == 3) return 1;
    if (fa.count(i)) return fa[i];
    return fa[i] = f(i/2) + f((i+1)/2);
}
```

#### 12. N皇后问题
```cpp
int vis[3][30];  // 0=列, 1=主对角(cur+i), 2=副对角(cur-i+n)
void search(int cur) {
    if (cur == n) { tot++; return; }
    for (int i = 0; i < n; i++) {
        if (!vis[0][i] && !vis[1][cur+i] && !vis[2][cur-i+n]) {
            vis[0][i]=vis[1][cur+i]=vis[2][cur-i+n] = 1;
            search(cur+1);
            vis[0][i]=vis[1][cur+i]=vis[2][cur-i+n] = 0;  // 回溯！
        }
    }
}
```
> **考点**：主对角 `cur+i` 恒定，副对角 `cur-i+n` 防负索引

### 🆕 第七组：新增题目

#### 23. 多case（三批输入）

**核心考点：三种输入结束方式的处理**

```
第一批：先给 CASE 数量 t，然后读 t 组
第二批：每组两个数，以 0 0 结束
第三批：一直读到文件尾（EOF）
```

> **计算内容**：每组给两个正整数，求 LCM（最小公倍数）
> 
> 公式：`LCM(m, n) = m * n / GCD(m, n)`

```cpp
int gcd(int m, int n) {
    if (m % n == 0) return n;
    return gcd(n, m % n);
}

int main() {
    int m, n, t;
    long long result;

    // 第一批：先给t，再读t组
    cin >> t;
    while (t--) {
        cin >> m >> n;
        result = (long long)m * n / gcd(m, n);
        cout << result << endl;
    }
    cout << "group 1 done" << endl;

    // 第二批：以"0 0"结束
    while (1) {
        cin >> m >> n;
        if (m == 0 && n == 0) break;
        result = (long long)m * n / gcd(m, n);
        cout << result << endl;
    }
    cout << "group 2 done" << endl;

    // 第三批：读到EOF结束（Ctrl+Z 或 文件尾）
    while (scanf("%d%d", &m, &n) > 0) {
        result = (long long)m * n / gcd(m, n);
        cout << result << endl;
    }
    cout << "group 3 done" << endl;
}
```

> **⚠️ 易错点**：
> 1. `m * n` 可能溢出，要用 `long long`：`result = (long long)m * n / gcd(m, n);`
> 2. 三批输入的**读取方式不同**，做完一批要输出标记
> 3. 第三批用 `scanf(...) > 0` 判断 EOF，`cin` 也可以但写法不同

```
第一批：先给t再循环   → while(t--)
第二批：读到0 0停     → while(1) { if(m==0&&n==0) break; }
第三批：读到EOF停     → while(scanf(...)>0)
```
